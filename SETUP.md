# Hotel Revenue DSS — Setup & Run Instructions (Week 10)

## 1. Requirements
- Python 3.10 or newer
- The packages in `requirements.txt`

## 2. Install
```bash
pip install -r requirements.txt
```

## 3. (Optional) Rebuild the data and models
The repository already includes the validated dataset and the two trained models,
so you can skip to step 4. To rebuild from scratch:
```bash
python code/generate.py          # rebuilds data/final/ (CSVs + hotel_dss.db)
python code/validate.py          # 22 data-integrity / fidelity checks (expect 22 PASS)
python train_models_wk10.py      # trains the two Gradient Boosting models (.pkl)
```

## 4. Run the application
```bash
streamlit run app.py
```
Streamlit opens the app in your browser (usually http://localhost:8501).

## 5. Using the app
Use the left sidebar to switch screens and pick a hotel.
- **Hotel Overview** — descriptive KPIs and the historical occupancy trend.
- **Overbooking Decision Support** — cancellation predictions + Monte Carlo overbooking.
- **Predictive Models & What-If** *(new in Week 10)* — for each KPI:
  overall predictor importance, an interactive what-if vs. a fixed baseline,
  per-prediction SHAP contributions, interpretation, and an auto-generated summary.

## Data access note
All data in `data/` is fully synthetic (generated by `code/generate.py`) and calibrated
to the public Antonio, de Almeida & Nunes (2019) hotel-booking dataset. There are no
confidential or access-restricted files, so everything needed to run the app is included.

## Troubleshooting
- "Database not found" → run `python code/generate.py` first, or run from the project root.
- "Prediction model not found" → run `python train_models_wk10.py`.
- SHAP install issues on Windows → `pip install --upgrade pip` then reinstall `shap`.
